📖 功能说明

🚀 快速上手

  1. 在「关键词管理」中添加关键词，可附带备注内容。
  2. 打开任意网页，匹配到的关键词会自动高亮。
  3. 用鼠标点击高亮词（或按 Enter 聚焦后回车）即可查看并固定备注卡片。
  4. 鼠标悬停高亮词时，只显示浏览器原生的文本小悬浮框；不弹备注卡片。

📝 关键词管理

  • 添加 / 编辑 / 删除：每个关键词可设置备注、分组、高亮颜色和匹配规则，可启用/禁用。
  • 批量导入：支持多行一次添加（关键字 | 备注），可选分隔符、分组、颜色和重复处理方式。
  • 搜索 / 筛选：可按关键词、备注搜索；按分组（含“未分组”）、状态（启用/禁用）、匹配方式筛选。
  • 排序：按最近更新 / 最近添加 / 名称 A→Z / Z→A 排序。
  • 分页：每页展示 50 条，数据量大时自动分页，不卡顿。
  • 批量操作：勾选多条后，可批量启用、禁用、移动分组、删除（二次确认）或取消选择。

📁 分组管理

  • 可创建、编辑、删除分组，并设置分组的默认高亮颜色。
  • 同一分组下的关键词颜色统一（分组颜色优先于关键词自身颜色）。
  • 关键词加入分组后自动应用分组颜色；修改分组颜色时组内关键词同步更新。
  • 通过批量操作可一键把多个关键词移动到指定分组。

🎨 匹配规则

  • 区分大小写：默认不区分大小写，可开启精确区分。
  • 全词匹配：只匹配完整独立的词（支持中文等 CJK 文本），不做部分匹配。
  • 正则表达式：高级模式，把关键词按正则解析（需自行转义特殊字符）。
  • 多个关键词同时命中时，长匹配优先，避免重叠与嵌套高亮。

🧩 单元格组合关键词匹配

  • 勾选「单元格特别标注」并填写后格期望值后，只有当该关键词命中位置的横向右侧相邻单元格匹配期望值时这个词才生效（高亮 / 重要笔记），否则整条不显示。
  • 支持两种结构：HTML 表格（td 的右侧相邻格），或文字中用 | / Tab 分隔的“假表格”（如 是否刚需|否）。
  • 匹配方式：默认「包含」（右侧格只要包含期望值即算命中，如 否（暂缓） 也算 否）；勾选「全词匹配」则要求右侧格整体与期望值相等。
  • 可独立设置：后格区分大小写（勾选后 wifi 与 WiFi 视为不同）、后格使用正则（期望值按正则匹配，可搭配“全词”做整体匹配）。
  • 可添加多条“同一关键词 + 不同后格”的规则（去重按前格 + 后格组合判断），便于同一词在不同语境下分别处理。
  • 与「重要笔记」互相独立，可叠加使用。

🌐 网页高亮

  • 自动查找并高亮关键词，动态加载的新内容也会自动高亮。
  • 自动跳过 script、style、code、pre、input、textarea 等不适合高亮的区域。
  • 支持 Shadow DOM 内的文本高亮（可在配置中开关）。
  • 高亮不会破坏网页原有结构和脚本。

💬 备注卡片

  • 点击高亮词显示备注卡片，再点同词、点页面其他位置或点 ✕ 关闭。
  • 卡片自动避让视口边缘，不会超出屏幕。
  • 支持一键复制备注内容。
  • 卡片样式（背景、文字、边框、圆角、阴影、宽度、透明度）可在「备注卡片样式」自定义。

📌 重要笔记

  • 关键词或分组可标记为重要；分组勾选重要后，组内关键词自动生效，取消则自动取消。
  • 重要关键词可单独填写一段重要笔记（长文本，与短备注相互独立）。
  • 页面命中重要关键词且填有重要笔记时，会在右上角弹出置顶悬浮笔记组件。
  • 多条命中会聚合在一个面板中，面板可拖动、可展开/收起为圆形小按钮。
  • 可单条关闭某条笔记（当前页面会话内不再显示）。
  • 重要笔记内容支持 Markdown，同样经过 XSS 防护。

🌐 站点控制

  • 默认所有网站生效；可在「站点规则」设置白名单或黑名单。
  • 支持域名精确、子域名、URL 前缀、正则四种匹配方式。
  • 工具栏弹窗可一键临时禁用当前站点，可全局暂停/恢复。

⌨️ 快捷键

  • Ctrl+Shift+H：开启/关闭全局高亮
  • Ctrl+Shift+S：临时禁用/启用当前站点
  • Ctrl+Shift+O：打开设置页

✍️ 备注格式

备注内容支持基础 Markdown：

  • **加粗** → 加粗
  • *斜体* → 斜体
  • [链接文字](https://example.com) → 可点击链接
  • 自动识别纯网址并生成可点击链接

💾 数据管理

  • 导出：可将全部关键词、分组、样式和站点规则导出为 JSON（含完整备份）或 CSV（仅关键词）。
  • 导入：支持从 JSON / CSV 恢复，导入前请先备份。
  • 重置：可一键清空所有本地数据并恢复默认设置。
  • 所有数据仅保存在浏览器本地 chrome.storage，不依赖服务器。

❓ 常见问题 Q&A

汇总使用过程中常见问题的解答，覆盖关键词、备注、重要笔记、站点规则、更新与隐私等。

Q1：备注支持哪些格式？换行能保留吗？

支持基础 Markdown：**加粗** → 加粗、*斜体* → 斜体、[文字](网址) → 可点击链接，纯网址也会自动变成链接。

换行可以保留：你输入的多行内容会原样显示（v1.6.4 起支持），无需加 <br>。

Q2：重要笔记为什么有时不弹、有时又弹？

重要笔记只在同时满足三点时弹出：①关键词被标记为重要（关键词自身或所属分组勾选“重要”）；②该关键词填写了重要笔记内容；③页面真的命中该关键词，且该命中在可见区域。

常见排查：隐藏元素（如 display:none 的菜单/模板/隐藏层）里的匹配不再触发重要笔记（v1.6.7 修复）；若命中后消失（如弹窗关闭），面板会自动隐藏。

Q3：检查更新/自动更新怎么用？没反应怎么办？

打开工具栏弹窗，点「🔍 检查更新」会立即查询 GitHub 是否有新版本；有新版时点「更新」可自动下载并覆盖（配合本机辅助服务可一键完成，未启动时回退为手动下载）。

若点了没反应，多为网络无法访问 github.com（v1.6.5 起会明确提示失败/超时），可稍后重试或手动覆盖 v1.6.8 安装包。

Q4：数据存在哪里？会不会泄露？

所有关键词、备注、设置都保存在本地浏览器（chrome.storage），不上传任何服务器。插件只在你浏览网页时查找并高亮关键词，不采集网页内容、关键词和备注。

Q5：黑名单和白名单有什么区别？

🚫 黑名单：加入的站点不高亮，其他网站照常生效（适合「只排除个别网站」）。

✅ 白名单：只有加入的站点才高亮，其他网站一律不高亮（适合「只在一两个网站用」）。

是否有“模式”开关？没有——规则是否生效由你添加的每一条规则自身的类型决定（v1.6.8 已移除易误导的模式单选）。

Q6：匹配对象“域名/网址”有什么区别？

域名：按网站域名匹配，例如 example.com 作用于整个网站。

网址：按完整网址（含路径）匹配，例如 https://example.com/admin —— 可针对同一站点下的某个分页单独处理，其他页面不受影响。

Q7：匹配方式有哪几种？

  • 域名精确匹配：仅匹配该域名本身。
  • 子域名匹配：覆盖该域名及其所有子域名（如 mail.example.com）。
  • URL 前缀匹配：以指定开头即命中。
  • 正则表达式：用正则灵活匹配（需自行转义）。

Q8：设了站点规则为什么没生效？

按优先级排查：① popup 里是否「临时禁用」了本站（徽标显示“已禁用”，优先级最高，会盖过规则）；② 网址级规则；③ 域名级规则；④ 未命中任何规则时：不存在白名单则默认高亮；只要存在任意一条白名单，则未命中的站点一律不高亮（白名单以外的网站都不生效）。黑名单只影响它命中的那一站点，不改变其他网站的默认状态。

Q9：同一网站的不同分页想用不同规则，能做到吗？

可以。添加规则时匹配对象选网址：例如某站列表页想高亮、后台页不高亮，就给后台网址加一条黑名单（网址·前缀），其他页面不受影响。

Q10：改完规则需要刷新页面才生效吗？

大部分情况无需手动刷新——保存后会自动重新评估并刷新当前页高亮；SPA 站内分页切换也随网址变化即时生效（v1.4.0 起）。仅偶尔出现旧高亮残留时按 Ctrl+F5 刷一次。

Q11：常见站点配置场景怎么弄？

  • 只在一个网站用：加一条白名单 example.com（域名·精确），其他网站都不高亮。
  • 只排除一个网站：加一条黑名单 example.com（域名·精确），其余网站都高亮。

    • Q12：单元格组合关键词匹配是做什么的？怎么用？

    用于“既要词对、也要后面那格对才算”的场景。例如数据表里 是否刚需|否，你想让词「是否刚需」只在它右侧是 否 时才高亮。做法：编辑该关键词时勾选「单元格特别标注」，在“后格期望值”填 否，右侧格包含 / 等于“否”才高亮，否则整条不出。

    几个细节：①支持 HTML 表格和文本 | / Tab 假表格；②“包含”与“全词”的区别——包含只要右侧格命中期望值即可（否（暂缓） 也算 否），全词要求右侧格整体等于期望值（否（暂缓） 不算）；③同一词可配多条不同后格规则并存，互不冲突；④右侧无相邻格或未命中时，该词不生效（不高亮）；⑤可与「重要笔记」叠加，命中且验证通过才弹笔记。

  • 某站后台分页不用高亮：加一条黑名单，匹配对象选网址，https://example.com/admin（网址·前缀）。

  • 高亮插入不会破坏网页原有结构和脚本。
