图片文字识别

关键词勾上「抓取后续字段」的「启用」、把要抓的「字段」填好后，再开启「识别图片文字」—— 这些字段的值格里的图片会被识别一次（普通词也能用，不再限组合词）； 识别出的文字里出现「图片命中关键词」，就算一次图片命中（显示在页面的「重要笔记」面板里，独立分区，不产生文字高亮）。
文字识别完全在本机运行：图片不上传，唯一的联网动作是下面这一次语言包下载（也可手动导入，做到完全离线）。

识别精度

两档各自独立保存语言包，切换不用重新下载；下面「语言包」一栏的下载 / 手动导入 / 清除都按当前档位生效。 高精度档用的是标准 LSTM 大模型（简体中文约 19MB），对艺术字 / 彩色底 / 照片上压字这类难图识别更准，但单张识别大约慢 2~4 倍。

帮助与隐私

🔒 隐私承诺

✅ 所有数据仅保存在您的本地浏览器中，不会上传到任何服务器。

✅ 插件不采集网页内容、关键词和备注。

✅ 关键词匹配、高亮、备注展示完全在本地完成。

✅ 仅浏览网页时在你的本机查找并高亮，不做任何云端存储或分析。

✅ 不记录、不上传任何浏览数据（无统计、无埋点）。

✅ 申请的权限（所有网站）仅用于在网页上查找和高亮关键词。

📖 功能说明

🚀 快速上手

  • 在「关键词管理」添加关键词，打开网页即自动高亮。
  • 标记「重要」的词，命中后在页面左上角弹出笔记。
  • 点击高亮词看备注；悬停只显示浏览器原生小提示。
  • 工具栏图标弹窗可快捷加词，不必进设置页。

🔑 关键词 · 基础用法

  • 增 / 删 / 改 / 启用停用，可设备注、分组、颜色、匹配规则。
  • 匹配规则：区分大小写 / 全词 / 正则，可叠加；表格里点「胶囊」勾选生效。
  • 管理：搜索、按分组/状态/类型筛选、排序、分页（每页 50）、勾选后批量操作。
  • 生僻字可用罕见字规则 hjz# 匹配（也可作组合核心）。

🗂️ 分组

  • 可建 / 改 / 删分组，设统一高亮颜色，组内自动跟随。
  • 分组可整组标记重要 + 填统一重要笔记，也可勾选「底色」。
  • 删除分组时，组内关键词自动移出分组，不会丢词。

🧩 单元格组合

  • 左右格：左格标题命中且右格含核心词才高亮；上下格＝表头列词 × 数据行词。
  • 支持真表格、ul/li、grid/flex「假表格」、|或 Tab 分隔的文字表。
  • 真表格可仅表头生效，避免数据区同文本误触发整列。
  • 仅抓取：关键词留空时只收集内容、不产生高亮。

📎 抓取后续字段

  • 地址|籍贯 可抓多标签；支持多行 / 合并单元格，表格化展示。
  • #1＝只取右邻一格；三方向层级（当前层/内层/外层，下拉 8 档可多选）。
  • 字段语法：#图 仅图片 / #3 最多 3 张 / @表达式 指定值格。
  • 新后缀：末尾 ! 去内部空格、%N 截前 N 字 / %a-b 截区间（不拆中文/emoji），如 包名!、简介#1%4。
  • 自动剔除按钮文字；图片仅接受 http/https。

📌 重要笔记

  • 词 / 组可标重要；命中且有内容 → 左上角置顶悬浮面板，多条聚合。
  • 可拖动、收起成圆钮、单条关闭（本次会话）；可看大图、相册翻页。
  • 配合「抓取 / 仅抓取」自动拼内容。
  • 图片尺寸按「关键词 > 分组 > 全局默认」取值（关键词那一档需本词勾「重要」才生效）。

💬 备注卡片

  • 点击高亮词弹出备注卡片，Esc / 滚动 / 再点关闭。
  • 卡片样式（背景 / 文字 / 边框 / 圆角 / 阴影 / 宽度 / 字号）可自定义。

🌐 网页高亮表现

  • 自动高亮 + 动态新内容自动亮；不破坏网页结构（纯视觉 Range 高亮）。
  • 跨文本节点也整词命中（如 审<span>核</span>不通过）。
  • 折叠内容算页面内容（含网站自做的展开/收起，可开关）；隐藏菜单 / 弹窗关闭态不误高亮。
  • 同中命中长匹配优先防重叠；跳过 script / code / pre / 输入框；Shadow DOM 可开关。

🎯 站点控制

  • 默认全站生效；可加白名单 / 黑名单。
  • 匹配对象：域名（整站）或网址（具体分页）；匹配方式有精确 / 子域 / URL 前缀 / 正则。
  • 工具栏一键临时禁用本站 / 全局暂停恢复。

🖼 图片识别（OCR）

  • 本地识别图片文字，匹配「图片命中关键词」。
  • 结果进面板「🖼 图片命中」分区，不产生文字高亮。
  • 识别全在本机；语言包按需下载 / 手动导入 / 自检；跨域图片按站点授权。

🩺 诊断与排查

  • 工具栏弹窗里可查看：整页重建 / 只刷面板次数、最近变更判定、命中规模、图片识别排队、组合词定位等。
  • 遇到「卡 / 不亮」先点它，再把数据提供给支持，能快速定位。

⌨️ 快捷键 & 更新

  • Ctrl+Shift+H：开启 / 关闭全局高亮
  • Ctrl+Shift+S：临时禁用 / 恢复当前站（与设置页顶部「本站开关」同通道）
  • Ctrl+Shift+O：打开设置页
  • 「ℹ️ 关于 → 版本信息」里可检查更新。

💾 数据管理

  • 导出：全部关键词、分组、站点规则、样式配置导出为 JSON（完整备份）或 CSV（仅关键词，关键词、组合方向等 18 列）。
  • CSV 列：关键词、备注、分组、启用、核心词区分大小写 / 全词 / 正则、背景色、文字颜色、重要、重要笔记、单元格组合、标题关键词(左格)、标题词匹配方式 / 区分大小写 / 使用正则、抓取后续字段，最后第 18 列是组合方向（lr 左右格 / tb 上下格，v2 新增）。注意：CSV 不含「抓取后续字段」的模块开关、图片识别三项（识别图片文字 / 图片命中关键词 / 每处最多）、尺寸、底色、取值格；要连这些一起搬走请用 JSON 导出。
  • 导入：从 JSON / CSV 恢复；可选择「合并」或「覆盖」，并逐块勾选导入范围。CSV 按列序取值，兼容旧版 17 列文件（缺的「组合方向」按左右格处理）；按分组名回建分组，缺失的分组自动创建。也可在「关键词管理」筛选栏点「📥 批量导入」直接导入 CSV / JSON。
  • 重置：清空所选数据并恢复默认设置。
  • 所有数据仅保存在浏览器本地 chrome.storage，不依赖、不上传任何服务器。

❓ 常见问题 Q&A

Q1：高亮 / 备注没生效，先查什么？

按顺序排查：① 顶部的总开关是否已开；② 本站是否被白名单/黑名单或「临时禁用」排除；③ 关键词是否已启用、匹配规则是否太严（全词 / 正则 / 区分大小写）；④ 单元格组合的左格标题是否对上、或「仅抓取」把右格判成了无内容；⑤ 动态加载的内容会自动高亮，无需刷新。

Q2：单元格组合怎么用？

以 是否刚需 | 否 为例：在关键词填 否、在标题关键词(左格)填 是否刚需。命中条件 = 左格标题命中 且 右格含核心。核心词规则用「匹配规则」区，标题词规则用「单元格组合」区里的标题词开关，两组互不影响。

Q3：「仅抓取」为什么不显示高亮？

这正是它的设计：只收集、不打扰原页面。右侧只有「编辑」等按钮、或内容为 -/空白时视为无内容，不命中。

Q4：重要笔记什么时候弹？

需同时满足：① 关键词或所属分组标记为重要；② 填有重要笔记，或走「抓取 / 仅抓取」产生了内容；③ 页面确实命中且元素可见。隐藏元素（菜单/模板）里的匹配不会弹。

Q5：白名单和黑名单有什么区别？

🚫 黑名单＝这些站点不高亮，其余照常；✅ 白名单＝只有这些站点高亮。生效与否由每条规则自身类型决定，没有全局「模式」开关。

Q6：匹配对象选「域名」还是「网址」？

域名＝整个网站（如 example.com）；网址＝具体分页（如 example.com/admin），可让同一站的不同页面单独生效或失效。

Q7：常见场景速配

  • 只在某站用：白名单加该域名（域名·精确）。
  • 排除某个站：黑名单加该域名。
  • 后台页不高亮：黑名单 + 匹配对象选「网址」+ 填后台网址前缀。
  • 表格先对标题再标内容：用「单元格组合」（关键词=右格、标题关键词=左格）。
  • 备注为空显示 -、仅展示有内容的备注：用「仅抓取」模式（关键词留空 + 标题关键词 + 抓取后续字段 + 重要）。

Q8：图片识别（OCR）怎么用？

在「🖼 图片识别」分区确保语言包可用（可下载 / 手动导入 / 自检）；开启后，图片里含「图片命中关键词」的文字会被识别并进面板「🖼 图片命中」分区，不产生文字高亮。跨域图片需先在「图片识别」里按站点授权。

Q9：抓取字段的 ! 和 %N 后缀是什么？

加在抓取字段末尾，用于清洗取值：! 去掉内容里的内部空格；%N 只取前 N 字、%a-b 取第 a~b 字（按字符截取，不拆开中文/emoji）。例 包名!、简介#1%4。

Q10：抓取的「层级」当前层 / 内层 / 外层是什么？

页面可能表格套表格。当前层＝命中格所在的那张表；内层＝当前层里嵌着的更小表格；外层＝当前层的祖先表。可多选，新建默认「当前层」。

Q11：更新日志去哪看？

设置页「ℹ️ 关于 → 版本信息」，可用右侧目录按版本号跳转；完整历史在欢迎页。

🛡️ 安全说明

  • 本地处理：关键词匹配、高亮、备注展示全部在本地完成，不上传任何网页或关键词数据。
  • 内容安全：备注 / 笔记与抓取的网页内容经清洗后再渲染，不会执行页面上注入的脚本；外部图片走协议白名单。
  • 最小权限：仅申请在网页上运行所需的权限。
  • 可备份：全部数据支持本地导出（JSON）随时备份、恢复或迁移。
