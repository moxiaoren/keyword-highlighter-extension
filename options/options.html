图片识别

关键词勾上「抓取后续字段」的「启用」并把「字段」填好，再开启「识别图片文字」—— 这些字段的值格里的图片就会被识别一次；识别出的文字里出现「图片命中关键词」就算一次图片命中 （落在「重要笔记」面板的独立分区里，不产生文字高亮）。 识别完全在本机运行：图片不上传，唯一的联网动作是下面这一次语言包下载（也可手动导入，做到完全离线）。

显示相关设置（缩略图尺寸、笔记字号）在侧栏的「样式 → 重要笔记」。

识别引擎

「识别档位」已经取消了。现在由主引擎负责识别质量，不用再选大语言包； 你的设置已自动改成自动（主引擎 + 兼容引擎兜底）。原来那两档语言包留着也不占额外空间， 想清掉可以在下面「兼容引擎语言包」里逐个清除。

主引擎 PP-OCR 在截屏里的小字上明显更快也更准（值格那种小图约 26ms， 整页约 0.5s）；兼容引擎 Tesseract 留着兜底，也供排查问题用。
识别都完全在本机跑，图片不上传；唯一的联网动作是下面两栏的资产下载（也都能手动导入，做到完全离线）。 实际用的是哪个引擎，会在识别结果的展开说明里写清楚 —— 降级了就不会瞒着你。

主引擎模型

PP-OCR 的三件模型（文字检测 + 文字识别 + 字符集，合计约 6.3MB，来自 PaddleOCR·Apache-2.0）。 首次用到才下载，下完做 sha256 与字节数双校验后存在本机；不想要联网就在这台机器上手动导入。

兼容引擎语言包

Tesseract 的中英快档语言包（合计约 3.7MB）。只有"自动兜底"或"只用兼容引擎"时会用到； 选了「只用主引擎」也可以不下载。

跨域图片

默认只识别同源 / data: / 页面自己声明过 CORS 的图片。其它网站的图片需要在这里按站点授权后，才会由扩展代为读取 （不新增任何浏览器权限，只是允许扩展去读你已经看到的那张图）。

两种「允许读这张图」的同意，一次说清（别混）：
· 站点授权＝长期：就是下面这个白名单。加进去之后，扩展在自动扫描时就能代读该站点的跨域图，一直有效，直到你把它移除。
· 右键单张＝一次性：在网页任意图片上点右键 → 识别你点的那一张，不必先加白名单；右键即代表你同意本次代为读取这张图。它不会把该站点写进白名单，下一张图还要你再点一次。
两条通路并存、互不取代：站点授权管「自动扫描时能不能代读」，右键管「你当下主动点的那一张」。

📖 功能说明

🚀 快速上手

  • 在「关键词管理」添加关键词，打开网页即自动高亮。
  • 标记「重要」的词，命中后在页面左上角弹出笔记。
  • 点击高亮词看备注；悬停只显示浏览器原生小提示。
  • 工具栏图标弹窗可快捷加词，不必进设置页。

🔑 关键词 · 基础用法

  • 增 / 删 / 改 / 启用停用，可设备注、分组、颜色、匹配规则。
  • 匹配规则：区分大小写 / 全词 / 正则，可叠加；表格里点「胶囊」勾选生效。
  • 管理：搜索、按分组/状态/类型筛选、排序、分页（每页 50）、勾选后批量操作。
  • 生僻字可用罕见字规则 hjz# 匹配（也可作组合核心）。

🗂️ 分组

  • 可建 / 改 / 删分组，设统一高亮颜色，组内自动跟随。
  • 分组可整组标记重要 + 填统一重要笔记，也可勾选「底色」。
  • 删除分组时，组内关键词自动移出分组，不会丢词。

🧩 单元格组合

  • 左右格：左格标题命中且右格含核心词才高亮；上下格＝表头列词 × 数据行词。
  • 支持真表格、ul/li、grid/flex「假表格」、|或 Tab 分隔的文字表。
  • 真表格可仅表头生效，避免数据区同文本误触发整列。
  • 仅抓取：关键词留空时只收集内容、不产生高亮。

📎 抓取后续字段

  • 地址|籍贯 可抓多标签；支持多行 / 合并单元格，表格化展示。
  • #1＝只取右邻一格；三方向层级（当前层/内层/外层，下拉 8 档可多选）。
  • 字段语法：#图 仅图片 / #3 最多 3 张 / @表达式 指定值格。
  • 后缀：末尾 ! 去内部空格、%N 截前 N 字 / %a-b 截区间（不拆中文/emoji）、^锚文本 只取锚点之前的内容，如 包名!、简介#1%4、名称^[复制]（执行顺序固定 ! → ^ → %）。
  • 自动剔除按钮文字；图片仅接受 http/https。
  • 某条字段取不到内容（值格空着、或整格什么都没抓到）时，这一项整张卡片都不出现 —— 不会只剩一个只有字段名的空壳让你点。

📌 重要笔记

  • 词 / 组可标重要；命中且有内容 → 左上角置顶悬浮面板，多条聚合。
  • 可拖动、收起成圆钮、单条关闭（本次会话）；可看大图、相册翻页。
  • 配合「抓取 / 仅抓取」自动拼内容。
  • 图片尺寸按「关键词 > 分组 > 全局默认」取值（关键词那一档需本词勾「重要」才生效）。
  • 同一处命中多个词时，条目上默认只显示最短的那一条；右边带一枚命中计数小标（如 ×3），点开条目上的下拉箭头就能看到全部命中（多个词分多行列出），点其中一项可切换主显示。
  • 同一条命中不会为了多值就铺开成好几条 —— 多出来的词都在那枚小标的下拉里，面板更省地方。
  • 点缩略图＝看大图（灯箱）。该图的全部识别文字在全文栏（浮层）里，默认就在大图右侧并排显示；不想看就点灯箱工具条上的眼睛开关收起（再点一次弹回来），按住栏的标题可把它拖到别处、双击标题回到大图右侧。栏里文字可选中，也可点栏里的一键复制，关掉大图即复位。图片条目上原来的 📋 复制按钮已移除，要整段文字请到这里取。
  • 面板宽度：默认 250px；「重要笔记 → 面板默认宽度」里可调 200–600px（长期值），面板右下角随时能拖（临时值）—— 两者的区别见「📖 功能 → 注意事项」。

💬 备注卡片

  • 点击高亮词弹出备注卡片，Esc / 滚动 / 再点关闭。
  • 卡片样式（背景 / 文字 / 边框 / 圆角 / 阴影 / 宽度 / 字号）可自定义。

🌐 网页高亮表现

  • 自动高亮 + 动态新内容自动亮；不破坏网页结构（纯视觉 Range 高亮）。
  • 跨文本节点也整词命中（如 审<span>核</span>不通过）。
  • 折叠内容算页面内容（含网站自做的展开/收起，可开关）；隐藏菜单 / 弹窗关闭态不误高亮。
  • 同中命中长匹配优先防重叠；跳过 script / code / pre / 输入框；Shadow DOM 可开关。

🎯 站点控制

  • 默认全站生效；可加白名单 / 黑名单。
  • 匹配对象：域名（整站）或网址（具体分页）；匹配方式有精确 / 子域 / URL 前缀 / 正则。
  • 工具栏一键临时禁用本站 / 全局暂停恢复。

🖼 图片识别（OCR）

  • 本地识别图片文字，匹配「图片命中关键词」。
  • 结果进面板「🖼 图片命中」分区，不产生文字高亮。
  • 识别全在本机；语言包按需下载 / 手动导入 / 自检；跨域图片按站点授权。
  • 长截图会分段识别，跨分块的重叠区里，同一条物理行自动去重合并，不会因为切块把同一行文字算两遍（原图里本来就重复的内容不会被吃掉）。
  • 大图（灯箱）里那张图的识别全文在全文栏（浮层）里与大图并排展示，默认就在右侧：可用工具条上的眼睛开关隐藏 / 显示，栏内文字可选中，还有一键复制（浮层隐藏时复制按钮一起隐藏）。按住栏的标题可把它拖到别处、双击标题回到大图右侧；关掉大图即复位。图片条目上原来的 📋 一键复制按钮已移除，要复制完整识别文字请到这个浮层里取。
  • 右键网页上任意一张图，可以直接识别那一张：在图片上点右键 → 「用高亮词识别这张图」，只读你点的那一张、不写进白名单（右键即同意本次代读）。结果落进面板的「🖼 图片命中」分区，标签是「已识别」、ℹ 图标，悬停看识别全文。安全边界：新入口只放行公网 http/https —— 本机回环、内网段、localhost 与 *.local / *.internal / *.home.arpa、IPv6 字面量一律拒绝且不发请求。

⚠️ 注意事项与已知局限

  • 「面板宽度」有两个值，别弄混：设置页「重要笔记 → 面板默认宽度」调的是默认值（长期值），200–600px、默认 250px，面板每次打开都按它来；面板右下角直接拖出来的是临时值，只对当前这一次显示有效、不写回设置，刷新页面就回到默认值。要「以后都这么宽」就在设置页改；只是这会儿嫌窄/嫌宽，拖右下角即可。两处数值不一样是正常的，不是没生效。
  • 命中词后面那个小数字是什么：面板每条笔记的命中词后面跟的裸数字（如 3）不是次数单位，而是该词在本页命中的处数（命中 1 处时不显示小标，2 处起才出现）；点开可看全部命中。
  • 「右键读图＝一次性同意」与「站点授权＝长期授权」：在网页图片上点右键 → 「用高亮词识别这张图」，右键即代表你同意本次代为读取这张图，只读你点的那一张、不写进白名单。而跨域图床的图，扩展默认读不到，必须在「图片识别 → 跨域图片」里按站点显式授权后，自动扫描时才会代读 —— 那是长期授权，登记一次以后都算数。两者不冲突：一次性的用右键，常去的站点进名单。
  • 跨域图未授权时的表现：这类图片在面板里照常显示，状态标成「跨域（未授权 域名）」（一个可动手的提示，不是故障）；把它那个域名加进本页「跨域图片」白名单，或直接在网页图片上右键识别这一张，就能读它。
  • 长截图去重的边界：去重认两种情形 —— ① 删掉空白后完全相同的行；② 同一物理行（竖直差 ≤8px）里很像但不完全相同的行（水平偏移 ≤16px）。②里长句按相似度 ≥0.8 判、且两次识别的置信度相差 ≥4 分才合并；短句（不足 6 字）改按单字相似度判（≥1/3 即同一行）—— 短串上「很像」很容易直接算成 0，按老口径会出现「你好啊」被两个切片各读错一个字、结果并排显示两行的情况。两条谁更可信由置信度决定，但不再因为「分不出高下」而两条都留。置信度咬得很近的长句仍会都留下 —— 宁可让你看到一条重复，也不猜着删掉真实内容。
  • 超长截图的切块上限：分段识别最多 40 块（约 7 万像素高），只有超过这个高度才会截断、超出部分不会被识别（是内容缺失，不是重复）。1080 宽的长图要到 14321px 才可能触发；真触发时面板会如实标注覆盖范围。

❓ 常见问题 Q&A

Q1：高亮 / 备注没生效，先查什么？

按顺序排查：① 顶部的总开关是否已开；② 本站是否被白名单/黑名单或「临时禁用」排除；③ 关键词是否已启用、匹配规则是否太严（全词 / 正则 / 区分大小写）；④ 单元格组合的左格标题是否对上、或「仅抓取」把右格判成了无内容；⑤ 动态加载的内容会自动高亮，无需刷新。

Q2：单元格组合怎么用？

以 是否刚需 | 否 为例：在关键词填 否、在标题关键词(左格)填 是否刚需。命中条件 = 左格标题命中 且 右格含核心。核心词规则用「匹配规则」区，标题词规则用「单元格组合」区里的标题词开关，两组互不影响。

Q3：「仅抓取」为什么不显示高亮？

这正是它的设计：只收集、不打扰原页面。右侧只有「编辑」等按钮、或内容为 -/空白时视为无内容，不命中。

Q4：重要笔记什么时候弹？

需同时满足：① 关键词或所属分组标记为重要；② 填有重要笔记，或走「抓取 / 仅抓取」产生了内容；③ 页面确实命中且元素可见。隐藏元素（菜单/模板）里的匹配不会弹。

Q5：白名单和黑名单有什么区别？

🚫 黑名单＝这些站点不高亮，其余照常；✅ 白名单＝只有这些站点高亮。生效与否由每条规则自身类型决定，没有全局「模式」开关。

Q6：匹配对象选「域名」还是「网址」？

域名＝整个网站（如 example.com）；网址＝具体分页（如 example.com/admin），可让同一站的不同页面单独生效或失效。

Q7：常见场景速配

  • 只在某站用：白名单加该域名（域名·精确）。
  • 排除某个站：黑名单加该域名。
  • 后台页不高亮：黑名单 + 匹配对象选「网址」+ 填后台网址前缀。
  • 表格先对标题再标内容：用「单元格组合」（关键词=右格、标题关键词=左格）。
  • 备注为空显示 -、仅展示有内容的备注：用「仅抓取」模式（关键词留空 + 标题关键词 + 抓取后续字段 + 重要）。

Q8：图片识别（OCR）怎么用？

在「🖼 图片识别」分区确保语言包可用（可下载 / 手动导入 / 自检）；开启后，图片里含「图片命中关键词」的文字会被识别并进面板「🖼 图片命中」分区，不产生文字高亮。跨域图片可以两条路走：在「图片识别」里按站点授权，或者在网页图片上直接右键识别你点的那一张 —— 右键即这一次同意扩展代读你点的那张，与站点白名单（长期授权）并存不冲突，口径见「🖼 图片识别 → 跨域图片」。

Q9：抓取字段的 !、%N、^锚文本 后缀是什么？

加在抓取字段末尾，用于清洗取值：! 去掉内容里的内部空格；%N 只取前 N 字、%a-b 取第 a~b 字（按字符截取，不拆开中文/emoji）；^锚文本 只取锚点第一次出现之前的内容（首尾空白顺带去掉），锚点找不到就保留原文。例 包名!、简介#1%4、名称^[复制]。三者可混写，执行顺序固定 ! → ^ → %，与书写顺序无关。

什么时候用 ^：抓取格里除了你要的值，还混着「复制」「高价值」这类控件 / 角标文字（多数按钮文字会被自动剔除，没认出来的那类会留在取值里），而前缀长度不固定、%N 定长切不动 —— 这时写 名称^[复制]，把锚点那截起全部切掉。

Q10：抓取的「层级」当前层 / 内层 / 外层是什么？

页面可能表格套表格。当前层＝命中格所在的那张表；内层＝当前层里嵌着的更小表格；外层＝当前层的祖先表。可多选，新建默认「当前层」。

Q11：更新日志去哪看？

设置页「ℹ️ 关于 → 版本信息」，可用右侧目录按版本号跳转；完整历史在欢迎页。

Q12：设置页改了「面板默认宽度」，为什么面板没跟着变？

「面板默认宽度」调的是默认值（以后每次打开的面板宽度，各站点共用这一份设置）；没拖过右下角的面板，这会儿正开着也会立刻跟着变。一旦拖过右下角，面板就按你拖出来的宽度显示 —— 那是临时值，只作用在页面上、不写进设置，此时再改设置页也不会顶掉它，刷新页面就回到默认值。填 200–600 之外会自动夹到边界，填了非数字则回到 250。

Q13：图片条目上的「📋 一键复制」去哪了？

已移除（图片条目上不再有那个按钮），完整识别文字请到大图（灯箱）的全文栏里取：该栏默认就在大图右侧并排显示，点一键复制，或在栏里选中后 Ctrl+C；用灯箱工具条上的眼睛开关收起 / 展开，复制按钮跟着它一起显隐（按住栏的标题可拖动、双击标题回位）。面板里点命中的词块，复制的仍是它所在的整句。

Q14：重要笔记里每个词的正文字号能单独设吗？

能（2.0.2.2 起）。全局默认在「🎨 样式 → 重要笔记 → 正文字号默认值」（10–20px，默认 11）；想只让某个词/分组不一样：打开该关键词（或分组）的编辑弹窗，在「重要笔记」区把字号填上 —— 该区要先勾选重要才会亮（关掉只是置灰，填过的内容保留）。留空＝继承全局默认。词级字号同时管住面板里的笔记正文与抓取字段表格；图片尺寸（同一区的「尺寸」）不走这条链路，它只管图片。

🛡️ 安全说明

  • 本地处理：关键词匹配、高亮、备注展示全部在本地完成，不上传任何网页或关键词数据。
  • 内容安全：备注 / 笔记与抓取的网页内容经清洗后再渲染，不会执行页面上注入的脚本；外部图片走协议白名单。
  • 最小权限：仅申请在网页上运行所需的权限。
  • 可备份：全部数据支持本地导出（JSON）随时备份、恢复或迁移。
