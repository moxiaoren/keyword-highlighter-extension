📖 功能说明

🚀 快速上手

  1. 添加关键词：在「关键词管理」点「➕ 添加」，填关键词和备注即可用；进阶可设分组、颜色、匹配规则、单元格组合、重要笔记。
  2. 打开网页：命中的关键词自动高亮；标记为「重要」的词会在右上角弹出笔记。
  3. 看备注：点击高亮词（或按 Enter 聚焦后回车）弹出备注卡片；悬停只显示浏览器原生小提示，不弹卡片。
  4. 快捷加词：工具栏弹窗点「＋ 快速添加」即可，不必进设置页。

🔑 关键词：基础用法

  • 添加 / 编辑 / 删除 / 启用禁用：每个关键词可设备注、所属分组、高亮颜色、匹配规则。
  • 备注内容：支持 Markdown 与图片；多行换行原样保留；悬停高亮词可快速查看。
  • 匹配规则：区分大小写（默认忽略，勾选后区分）、全词（只匹配完整词，中文也按整词）、正则（高级，如 \d+、\p{L} 匹配任意中文/字母）——可叠加使用。
  • 管理：支持搜索、按分组/状态/匹配方式筛选、排序、分页；勾选后可批量启用、禁用、移动分组、设置备注/重要笔记、删除。

🗂️ 分组

  • 可创建/编辑/删除分组，并设统一高亮颜色——组内关键词自动跟随，改分组色组内同步。
  • 分组可整组标记重要并填统一重要笔记，省去逐个设置。
  • 批量操作可一键把多个关键词移入指定分组。

🧩 单元格组合：左格标题 + 右格内容

场景：数据表里想「先对标题、再标内容」。例如 是否刚需 | 否，只想让右格 否 在左格是「是否刚需」时才高亮/弹笔记。

  • 怎么配：编辑关键词时展开「单元格组合」，在关键词填右格内容（如 否），在标题关键词(左格)填左格标题（如 是否刚需）。命中条件 = 左格标题命中 且 右格含核心；高亮/备注/重要笔记统一挂在右格。
  • 支持两种结构：真实 HTML 表格（取左侧相邻格当标题）；或文字中用竖线 | / Tab 分隔的「假表格」（左段标题、右段核心）。
  • 匹配方式：默认「包含」——右格只要包含核心即命中（否（暂缓） 也算 否）；勾选全词则要求右格整格等于核心。还可设区分大小写、用正则（配合「全词」可锁定右格为某类内容）。
  • 仅抓取模式：把「关键词」留空，只填「标题关键词」和「抓取后续字段」——当该标题格右侧有真实内容（非空、非 -、非纯标点）时，自动把右格内容抓进重要笔记，页面不产生任何高亮。适合「备注为空显示 -、仅当有真实内容时才展示备注」；右侧的「编辑」等按钮文字会自动剔除，右格按视觉行合并/分行并展示成表格。
  • 同一标题可配多条不同核心的规则并存。

📎 抓取后续字段

  • 命中关键词时，自动读取指定标签右侧单元格内容拼入重要笔记；多个标签用 | 分隔，如 地址|籍贯。
  • 抓取内容在重要笔记里以表格形式规整展示（支持多行、多级合并单元格、多字段合并）。
  • 字段末尾加 #1（如 备注信息#1）为简单模式：只取右侧相邻一个单元格，展示为 字段 | 值。
  • 抓取时会自动剔除「编辑 / 查看更多」等按钮文字。

📌 重要笔记

  • 关键词或整组都可标记为重要；重要词可单独填写一段重要笔记长文本。
  • 命中且有笔记时，在右上角弹出置顶悬浮笔记；多条自动聚合在一个面板，可拖动、展开/收起成圆形小按钮（双击展开）、可单条关闭。
  • 可配合「抓取后续字段 / 仅抓取模式」自动把页面内容拼入笔记；也支持图片显示与 Markdown。
  • 页面隐藏元素（如菜单/模板）里的匹配不会误弹笔记。

💬 备注卡片

  • 点击高亮词显示备注卡片；再点同词、点页面其它位置或 ✕ 关闭。
  • 卡片自动避让屏幕边缘；支持一键复制、展示图片。
  • 卡片样式（背景、文字、边框、圆角、阴影、宽度、透明度）可在「备注卡片样式」页自定义。

🌐 网页高亮表现

  • 自动高亮，动态加载的新内容也自动高亮；不破坏网页结构。
  • 自动跳过 script、code、pre、输入框等不适合高亮的区域；支持 Shadow DOM 内文本（可开关）。
  • 多个关键词同时命中时长匹配优先，避免重叠与嵌套高亮。

🎯 站点控制

  • 默认所有网站生效；可在「站点规则」加白名单（只这些站高亮）或黑名单（这些站不高亮）。
  • 支持按域名（整个网站）或网址（具体分页）匹配；匹配方式有域名精确、子域名、URL 前缀、正则。
  • 工具栏弹窗可一键临时禁用本站、全局暂停/恢复；快捷键 Ctrl+Shift+S 最顺手。

⌨️ 快捷键

  • Ctrl+Shift+H：开启/关闭全局高亮
  • Ctrl+Shift+S：临时禁用/启用当前站点
  • Ctrl+Shift+O：打开设置页

✍️ 备注 / 笔记格式

支持 Markdown 常用语法与图片：

  • **加粗** → 加粗；*斜体* → 斜体
  • [文字](网址) → 可点击链接；纯网址自动转链接
  • ![说明](图片网址) → 显示图片（备注卡片 / 重要笔记均可，点击可看原图）
  • 多行换行原样保留；| 列1 | 列2 | 可渲染成表格

💾 数据管理

  • 导出：把全部关键词、分组、样式、站点规则导出为 JSON（完整备份）或 CSV（仅关键词）。
  • 导入：从 JSON / CSV 恢复；建议导入前先导出备份。
  • 重置：一键清空所有本地数据并恢复默认设置。
  • 所有数据仅保存在浏览器本地 chrome.storage，不依赖、不上传任何服务器。

❓ 常见问题 Q&A

汇总常见问题，覆盖高亮排查、单元格组合、仅抓取、重要笔记、站点规则、更新与隐私等。

Q1：高亮 / 备注没生效，先查什么？

按顺序排查：① 工具栏弹窗里的总开关是否已开；② 本站是否被白名单/黑名单或「临时禁用」排除；③ 关键词是否已启用、匹配规则是否太严（全词 / 正则 / 区分大小写）；④ 单元格组合的左格标题是否对上、或「仅抓取」把右格判成了无内容；⑤ 动态加载的新内容通常会自动高亮，无需刷新。

Q2：备注 / 重要笔记支持哪些格式？

支持基础 Markdown：**加粗**、*斜体*、[文字](网址)（纯网址自动转链接）、![说明](图片网址) 显示图片（可点击看原图）、| 列1 | 列2 | 渲染成表格。多行换行原样保留。

Q3：单元格组合（左格标题 + 右格内容）怎么用？

适合「先对标题、再标内容」。以 是否刚需 | 否 为例：在关键词填 否、在标题关键词(左格)填 是否刚需。命中条件 = 左格标题命中 且 右格含核心，二者同时满足才高亮/弹笔记，否则整条不出。真实表格取左邻格当标题；文字用 | / Tab 分隔亦可。配套选项：全词（右格整格相等）、区分大小写、用正则（配合全词可锁定右格为某类内容）。

Q4：「仅抓取」模式怎么配？为什么不显示高亮？

仅抓取＝把「关键词」留空，仅填「标题关键词」和「抓取后续字段」并勾选「重要」。当该标题格右侧有真实内容（非空、非 -、非纯标点）时，自动抓右格内容进重要笔记，页面不产生任何高亮——这正是它的设计（只收集、不打扰原页面）。右侧只有「编辑」等按钮、或内容为 -/空格时，视为无内容不命中；抓取时会自动剔除按钮文字、按视觉行合并/分行并展示成表格。

Q5：重要笔记什么时候弹？怎么不弹了？

需同时满足：① 关键词或所属分组标记为重要；② 填有重要笔记 / 或走「抓取 / 仅抓取」模式产生了内容；③ 页面确实命中且内容在可见区。隐藏元素（菜单/模板）里的匹配不会弹。面板支持拖动、展开/收起成小圆钮、单条关闭。

Q6：白名单和黑名单有什么区别？

🚫 黑名单＝这些站点不高亮，其余照常（适合「只排除个别网站」）；✅ 白名单＝只有这些站点高亮（适合「只在某几个站用」）。生效与否由每条规则自身的类型决定，没有全局"模式"开关。

Q7：匹配对象选「域名」还是「网址」？

域名＝整个网站（如 example.com）；网址＝具体分页（如 example.com/admin），可让同一站的不同列表页 / 后台页单独生效或失效，互不影响。

Q8：设了站点规则但没生效？

排查顺序：① 是否「临时禁用」了本站（该开关优先级最高）；② 网址级 / 域名级规则是否写对；③ 未命中任何规则时——只要存在白名单，白名单以外的站点一律不高亮；没有白名单则默认高亮。黑名单只影响它命中的站点。

Q9：如何更新到新版本？

工具栏弹窗点「🔍 检查更新」，有新版本点「更新」自动下载覆盖（配合本机辅助服务可一键完成）。若提示网络异常，稍后重试或手动覆盖安装包。建议更新前在「数据管理」先导出备份。

Q10：数据会泄露吗？

不会。所有关键词、备注、设置、统计仅保存在本地浏览器，不上传任何服务器；匹配、高亮、笔记展示完全在本地完成，仅申请浏览网页所需的最小权限。

Q11：常见场景速配

  • 只在某站用：白名单加该域名（域名·精确）。
  • 排除某个站：黑名单加该域名。
  • 后台页不高亮：黑名单，匹配对象选「网址」，填后台网址前缀。
  • 表格先对标题再标内容：用「单元格组合」（关键词=右格、标题关键词=左格）。
  • 备注为空显示 -、仅展示有内容的备注：用「仅抓取」模式（关键词留空 + 标题关键词 + 抓取后续字段 + 重要）。

🛡️ 安全说明

  • 本地处理：关键词匹配、高亮、备注展示全部在本地完成，不上传任何网页或关键词数据。
  • 内容安全：备注 / 笔记与抓取的网页内容经 XSS 防护清洗后再渲染，不会执行页面上注入的脚本；外部图片链接受控。
  • 最小权限：仅申请在网页上运行所需的权限，用于查找与高亮关键词，不读取无关数据。
  • 可备份：全部数据支持本地导出（JSON）随时备份、恢复或迁移。
