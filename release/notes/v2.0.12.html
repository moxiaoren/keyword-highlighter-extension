高亮词助手 2.0.12
2026-11-16 · 稳定版稳定版
这一版改了什么、为什么改；条目与扩展内「更新日志」同源。
  • 新增·比对写进添加关键词
    图片命中关键词 / 图片动态关键词的每一行，多了「进表 / 比对」两枚勾选：勾上「比对」就等于声明「这张图上必须出现这一项」，同一张图上勾了的项全在＝一致，缺哪一个会点名；静态词按词判、动态字段按它这次抓到的值判。抓取后续字段的每一行也多了「比对」勾选，且必须选「和谁比」（落库写成 开发者#比=著作权人）：两边都有值才判，相等＝一致，不等＝待确认并写出两边值。
  • 新增·比对结论只有一句
    每张图的悬停第一句就是比对结论（一致 / 不一致：缺 X），卡片头上多一枚汇总（✓ 比对一致 / ⚠ 比对不一致：缺 X / 比对待识别…）。逐字段的「值：… · 源：本页抓取 · 法人未查到 · 读取：08:43」这类证据行整条删掉，不再占版面。
  • 改动·软著三方比对退场
    表格下方的结论行、设置页「软著三方比对」那张全局比对表都不再有了——同样的核对可以用关键词里的比对配出来。设置项 imgCompare 一并退场，老配置不影响使用。
  • 改动·内置兜底退场
    企业名称 ↔ 开发者、承诺对象 ↔ 放行名单、著作权人 / 主办单位 ↔ 开发者 这三条自动兜底不再默默参与。要判就明确配：勾「比对」并选对象；不配就不判、不涂色，也不再显示 ⚙ 待配置 的噪声。
  • 保留·开发者 ↔ 核准主体名称
    这一对仍单独走同法人链路：同名直接算同一主体不联网；名字不同就查两家法人，同法人也算一致；查不到如实写「未查明」。只有这一对查法人，其它字段对只做字面比对。
  • 修复·法人查询不再张冠李戴
    通道换成：先在不激活的后台标签页里读爱企查（登录态可用时最准），失败再走 360 三种问法；解析必须校验查询名就在“法定代表人”前面不远处，中间插了别家名字一律不认。此前会把「相关企业」里别家的法人当成本家的（实测曾把杭州矩远答成“哔哩哔哩”）。查不到就写查不到，6 小时内不重复联网。
  • 改动·证书编号放宽
    软著证书 / APP 电子版权证书自动进表的登记号（＝认证号，只是叫法不同）改成按形状认：年号 + 1~3 位字母 + 5~10 位数字，如 2023SR0488550、2026S0635345。逐字带空格的标签（著 作 权 人：/ 登 记 号：）也照取；「证书号 软著登字第 N 号」仍不会被当成登记号。
  • 改动·校验中心只汇总
    设置页「🧭 校验中心」保留两行（图怎么取 / 谁和谁比），「谁和谁比」改成只读汇总各关键词里标的比对；没标就明说「抓取字段之间不做判等」，不再提供第二个配置入口。
  • 自检
    单测 1266 项全过（0 跳过），机械红线 72 条全绿，真机内容层 87 + UI 层 162 = 249 项全过。
