1

批量管理 / 迁移
设置页可筛选、批量改色 / 分组 / 启停，也能导入旧版导出的 JSON 或 CSV。碰到图里的字，直接在图上右键识别。
去「导入导出」›

快捷键

在普通网页上生效（浏览器内置页 / 扩展商店 / PDF 上无效）
Ctrl+Shift+H 暂停 / 恢复全局高亮 Ctrl+Shift+S 临时禁用本站 Ctrl+Shift+Y 打开设置

按键可在浏览器「扩展程序 → 管理扩展 → 快捷键」里自定义；显示「未分配」表示浏览器没给它分按键（例如被浏览器自带快捷键占用）。
