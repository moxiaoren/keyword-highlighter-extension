它能做什么

🔍
关键词高亮
普通词 / 正则 / 全词 / 区分大小写。命中只做视觉上色，不插入任何节点、不改网页内容。
▦
单元格组合
「左格标题 ＋ 右格核心」或「表头列 ＋ 数据行」——两格都命中才生效，避免半截误标。
📌
抓取 ＋ 重要笔记
命中后把同行的其它字段一并抓走，聚合在可拖动的悬浮面板里；点高亮词还能单独看该词备注。
🎨
分组与配色
每个词可单独设底色 / 文字色，分组设一次组内共用。优先级：分组色 > 词色 > 全局默认。

三步上手

1
加第一个词
工具栏图标 →「＋ 快速添加」，编辑器直接弹在当前网页上。
2
调样式（可选）
在「样式」里改全局默认色与备注卡片外观，改动即时预览。
3
批量管理 / 迁移
设置页可筛选、批量改色 / 分组 / 启停，也能导入旧版导出的 JSON 或 CSV。

快捷键

在任何网页上生效
Ctrl+Shift+H 暂停 / 恢复全局高亮 Ctrl+Shift+S 临时禁用本站 Ctrl+Shift+O 打开设置
