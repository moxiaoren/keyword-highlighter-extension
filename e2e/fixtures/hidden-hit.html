隐藏容器里的关键词**不该**命中（用户实测：页面上看不见却被高亮）

① 可见的（应命中 1 处）

状态：审核不通过

② 自己 display:none（应 0 处）

状态：审核不通过

③ **祖先** display:none，中间还隔了两层（应 0 处）—— 用户实际遇到的就是这种

状态：审核不通过

④ visibility:hidden（应 0 处）

状态：审核不通过

⑤ hidden 属性（应 0 处）

状态：审核不通过

⑥ 取巧：visibility:hidden 的祖先里，后代自己 visibility:visible（**应命中**）

状态：审核不通过

判据：不渲染（display:none / content-visibility:hidden / hidden）→ 整棵子树剪掉； visibility:hidden → 只跳过自己，后代用 visible 可以把自己重新显示出来。
