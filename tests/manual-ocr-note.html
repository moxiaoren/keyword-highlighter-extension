人工验证页 · 图片 OCR 命中 + 重要笔记面板

怎么点、看什么
  1. 面板在哪：左上角固定悬浮的白色卡片（真实模块的 Shadow DOM）。看不到就点浏览器地址栏按一下回车刷新。
  2. 图片命中列表（面板下半部分「🖼 图片」）：默认只显示命中与失败两种状态 — 这是真实口径。点题头右边的「全部 3」把「未命中 / 识别中 / 排队中」也放出来。（面板宽 250px 后题头与每行都改图标 + 短标签：✓命中 ✕未命中 ⟳识别中 ⚠失败 ℹ其它；长文案挪到鼠标悬停。）
  3. 图片条目里没有「📋 复制全文」了（2.0.1.15 需求 7 删掉）：条目只有 缩略图 + 「命中」标记 + 命中的词（词块）。点命中的词仍是复制含它的那一整句（见下一条）；要看/复制完整识别文字就点缩略图进大图 —— 全文在右侧浮层里显示、可选中复制。该浮层默认隐藏，靠灯箱工具条上的开关（眼睛）弹出/收起；关掉大图即复位。
  4. 命中词块（图下面的蓝色小方块）：点它复制含这个词的整句；也可以用 Tab 聚焦后按 Enter/空格。剪贴板里拿到的应该是一整句，不是光秃秃一个词。
  5. 点缩略图：开灯箱看大图，该图的识别全文在右侧浮层里（识别出的文字）—— 该浮层默认隐藏，点灯箱工具条上的开关（眼睛）弹出/收起，关掉大图即复位；多张图时可以 ← → 翻页、Esc 关闭。
  6. 重要笔记卡片（面板上半部分）：夹具里有两张 —— 一张是 markdown + 抓取字段表格（多行、带 rowspan），一张是「同标题多值 → 聚合标签」的形态。点卡片右上角 ✕ 会真的把这张卡从面板移除（真实口径：记进 ignored 后 refresh）。
  7. 字号输入框（下面工具栏，10–20）：改一下立刻能看到卡片正文与表格文字变大变小；面板正文字号来自 CSS 变量 --kh-note-fs，由 panel.render() 写到宿主上。
  8. 面板实测宽度：下面实时显示 getBoundingClientRect().width —— 这是宽度真源 .khin-panel { width } 的实测值（面板右下角还能手动 resize，拖一下数字会变）。
