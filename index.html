🔍 关键词高亮扩展 · 自动更新源

此页面为扩展自动更新协议所需的托管资源，非插件商店。

  • 更新清单：update.xml
  • 最新版本安装包：release/ 目录下的 .crx 文件

扩展通过清单中的 update_url 定期检查此处的版本，发现新版即自动静默更新，无需手动覆盖。

一键安装 + 自动更新（Edge / Chrome）

本扩展不在商店里，但可以用下面的脚本让浏览器**自动安装并持续自动更新**（稳定版或测试版都可以）：

  1. 下载 kh-autoupdate.bat
  2. 右键 → 以管理员身份运行（写机器级注册表需要）
  3. 菜单里选：Edge 或 Chrome × 稳定版或测试版
  4. 完全退出浏览器再启动 —— 扩展会自动装上，之后线上发版即自动更新

卸载：再运行一次脚本选「7」。注意：卸载会清空扩展自己的数据（关键词/分组），请先到设置页导出 JSON 备份。
