关键词高亮 · 浏览器扩展

在任意网页上高亮你关心的关键词；重要字段自动抓取成「重要笔记」面板。适用于 Edge / Chrome（免登录、数据只存本地）。

一键安装 + 自动更新（推荐，稳定版 / 测试版都支持）

下载 kh-autoupdate.bat（一键安装）

  1. 下载上面的 kh-autoupdate.bat
  2. 右键 → 以管理员身份运行（要写机器级注册表，让浏览器认这个扩展）
  3. 运行后菜单里选：**Edge / Chrome** 以及 **稳定版 / 测试版**（两个通道都能装，也可以都装）
  4. 完全退出浏览器再启动（有时要启动两次）—— 装好后线上发新版即自动静默更新

卸载 / 查状态：重新运行同一个 bat，用它的菜单里对应项。

它做什么


    
  
  • 关键词高亮：命中只做「视觉高亮」（不改动网页 DOM），页面自身的样式与脚本不受影响；隐藏容器里的内容不会误命中。
    • 
  
  • 组合词：给核心词加「定位限制」——左格标题命中后，右格（或该列）里的核心词才算命中；上下格（表头 × 数据行）同理。
    • 
  
  • 跨文本节点命中：页面把词拆成 审<span>核</span>不通过 也照样命中，整词上色、两段各自颜色都保留。
    • 
  
  • 后续字段抓取：命中后顺带把同表字段抓成结构化表格（多行 / 合并单元格 / 图片；字段#图 仅图片、字段#3 只取前 3 张）。
    • 
  
  • 重要笔记面板：把抓到的内容汇总成可拖动面板；图片可点开看大图（缩放 / 旋转 / 同格翻页）。
    • 
  
  • 备注卡片 / 悬停提示：给词写 Markdown 备注，点一下或悬停即看。
    • 
  
  • 分组与配色：20 色板 + 可拖动取色器 + 色值输入；分组可统一配色与图片尺寸。
    • 
  
  • 罕见字规则：关键词填 hjz# 即对罕见汉字着色，也可作组合词核心。
    • 
  
  • 站点规则：黑白名单（含网址级）、临时禁用本站、全局开关。
    • 




常见问题



  
现象原因 / 处理

  
商店搜不到没上架商店：用 bat 一键装，或按上面的步骤手动加载

  
装了没反应要完全退出浏览器再启动；并确认该站点没被「站点规则 / 临时禁用」拦掉

  
稳定版 / 测试版怎么选日常用稳定版；想先试新功能用测试版（两者可共存、各自自动更新）

  
数据会不会上传不会。关键词、备注、抓取内容都只存在浏览器本地（chrome.storage）
