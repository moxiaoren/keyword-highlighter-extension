关键词高亮 · 浏览器扩展

在任意网页上高亮你关心的关键词；重要字段自动抓取成「重要笔记」面板。适用于 Edge / Chrome（免安装、免登录、数据只存本地）。

下载 kh-autoupdate.bat（一键安装） 下载 .crx 历史版本 / Release

  1. 下载上面的 kh-autoupdate.bat
  2. 右键 → 以管理员身份运行（要写机器级注册表，让浏览器认这个扩展）
  3. 菜单里选：Edge 还是 Chrome × 稳定版还是测试版
  4. 完全退出浏览器再启动（有时要启动两次）—— 扩展自动装好，之后线上发新版即自动静默更新

卸载 / 查状态：重新运行同一个 bat，用它菜单里的对应项。

它做什么

  • 关键词高亮：命中只做「视觉高亮」（不改动网页 DOM），页面自身的样式与脚本不受影响。
  • 组合词：给核心词加一个「定位限制」——只有左格标题命中后，右格（或该列）里的核心词才算命中； 上下格组合（表头 × 数据行）同理。
  • 跨文本节点命中：页面把词拆成 审<span>核</span>不通过 这种也照样命中， 整词上色、两段各自的颜色都保留。
  • 后续字段抓取：命中后顺带把同表里的字段（如「驳回原因 / 运营备注」）抓成结构化表格； 支持多行、合并单元格、图片（字段#图 仅图片、字段#3 只取前 3 张）。
  • 重要笔记面板：勾了「重要」的关键词把抓到的内容汇总成面板，可拖动、可收起成小圆球； 图片可点开看大图（缩放 / 旋转 / 同格翻页）。
  • 备注卡片 / 悬停提示：给词写 Markdown 备注，点一下或悬停即看。
  • 分组与配色：底色 / 文字颜色可选（20 色板 + 可拖动取色器 + 色值输入），分组可统一配色与图片尺寸。
  • 罕见字规则：关键词填 hjz# 即对「罕见汉字」着色，也可当作组合词的核心词。
  • 站点规则：黑白名单（含网址级）、临时禁用本站、全局开关；所有配置只存在浏览器本地。

手动安装（不用 bat 时）

  1. 下载上面的 .crx（打不开 crx 就下载 .zip 并解压成一个目录）
  2. 打开 edge://extensions 或 chrome://extensions，打开右上角开发者模式
  3. 把 .crx 拖进页面（或「加载解压缩的扩展程序」选解压出来的目录）
  4. 手动装不会自动更新：每次发新版需要重新下载安装

关于更新通道

  • 本页是扩展的自动更新源：浏览器按下面的清单定期检查，发现新版本即静默更新。
  • 测试版清单：update-beta.xml · 稳定版清单：update.xml · 版本信息：latest-beta.json / latest.json
  • 测试版与稳定版是两个扩展（ID 不同）：可以同时装；测试版晋级稳定版后需要换装一次。
  • 更新日志在扩展内「帮助与隐私 → 更新日志」；每个版本的安装包同时挂在 GitHub Releases。

常见问题

现象原因 / 处理
扩展商店搜不到没上架商店，用上面的 bat 或手动加载；bat 需要管理员权限
装了但页面没反应装完要完全退出浏览器再启动；还要确认该站点没被「站点规则 / 临时禁用」拦掉
大表格页面变慢已对上千行表格做过性能优化（抓取去二次方、扫描按格复用缓存）；如仍异常请带上页面结构反馈
数据会不会上传不会。关键词、备注、抓取内容都只存在浏览器本地（chrome.storage）
